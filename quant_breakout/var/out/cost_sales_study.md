# 成本 × 销售：销售特别好能不能盖过原材料成本、销售好时选间接（2026-09-28；git 12a49c7；数据指纹 3196547bcaee）
规则见 scripts/cost_sales_study.py 开头（先提交后运行）。横截面 = 18 个业种。各差 = 之后 3 个月的相对收益 %（上半平均 − 下半平均）。

## S1（主）「销售盖过成本」：成本压力大的业种里，销售强的一半 − 弱的一半
- 平均 -0.149%（t -0.23，174 个月）；两半 0.319 / -0.606；命中率 46.6%（3 种起点 [50.0, 46.6, 41.4]）；对照 t 的 95% 分位 1.78、经验 p 0.487；去掉任何一个业种后平均最低 -0.571
- 对照组（成本压力不大的业种里同样分）：平均 -0.204%（t -0.58，236 个月）；两半 -0.4726 / 0.0681；命中率 43.6%（3 种起点 [51.9, 43.0, 43.6]）；配对差 S1 − 对照 = -0.1251（t -0.19）
- 判定：无效：平均 -0.1488（t -0.23）不够；两半 0.319 / -0.606 不都 > 0；命中率 46.6% < 55.0%；去掉某一个业种后平均最低 -0.571 ≤ 0；对照经验 p 0.487（Holm 后）不够 → **无效**

## S2（主）「销售好时选间接」：成本上升的月份、销售好（前一半）且成本上涨的业种里，间接占比高的一半 − 低的一半
- 平均 +1.227%（t 2.65，125 个月）；两半 1.3626 / 1.1101；命中率 61.9%（3 种起点 [59.5, 61.9, 63.4]）；对照 t 的 95% 分位 1.83、经验 p 0.0052；去掉任何一个业种后平均最低 0.8232
- 基准（同样月份、不看销售的全部成本上涨业种）：平均 +0.333%（t 0.84，141 个月）；两半 0.895 / -0.175；命中率 59.6%（3 种起点 [51.1, 61.7, 59.6]）；配对差 S2 − 基准 = 0.8174（t 2.1）
- 判定：有效 → **销售好时偏间接的更好（销售这一条件起作用）**
