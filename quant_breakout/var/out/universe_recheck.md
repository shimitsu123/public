  闲置资金按原规则 1655 的账户（离场研究）：Calmar 0.311 → 0.319、0.403 → 0.401。
- **名额数 / 一手放宽**（capital_study，结论字段变了）：最优在「2 个名额」（213 只）与「4 个名额 + 一手放宽 U2」（225 只）之间换边，
  差都在门槛边上（213 只：U2 的 20 年 Calmar 0.367 < 现行 0.368；225 只：2 个名额的主窗口 0.475 < 0.445 + 0.05）。
  225 只下与登记时（115c662）的结论相同（U2）；2026-09-27 撤回 U2 的理由（换成 J-Quants 行情结论就反过来、单只最多约占权益 50%）不受这次影响 →
  不提议恢复 U2，也不提议 2 个名额（在新股票池下不过门槛）。这次换边本身又是一个「效果不稳健」的例子。
- **放量突破加强版 V1〜V4**（登记时的基准，不开 W2）：V3 在 213 只下过门槛、225 只下不过 —— 加回的 12 只让「不加过滤」的基准变好了
  （2006〜2016 Calmar 0.218 → 0.230、后半 0.844 → 0.959），V3 自己没变（约 0.27）；按规则选 W2 的决定两边都不变。
- **S6 指标两两搭配搜索**（K1〜K3 的来源，探索、不登记）：213 只下过筛选的 1 个组合正是「突破日量比高 ∧ 对日経 β 低」，225 只下 0 个
  （打乱结果的偶然基线最多 1 个）；K1〜K3 的登记确认（leap2_s6_study）两边都是「飞跃 ✗ / 改进 ✗」→ K2 的证据更弱，但 K2 只是前向记录（不交易），照旧记录。
- **卖出判定确认的 H3**（死叉的卖对率 − 持有期里随便一天的卖对率，|差| < 3 pp 算成立）：213 只 3.04 pp（不成立）、225 只 2.44 pp（成立，与登记时 2.86 相同方向）
  → 门槛边上的换边；主结论「能提高胜率的卖法都把赢家卖早」两边都确认。
- **楽天美股 vs 立花日経**：日本 225 只、美股也加回航空运输 / 服装 / 食品饮料餐饮 / 日用品综合零售（449 → 497 只）→ 仍然「日経（立花）更好」。
  （new 与 newus 的日本侧应当相同，实际 2017〜 的笔数 92 vs 88：这个研究的日本与美国共用一个引擎、两次运行相隔约 45 分钟，没有逐笔查原因；不影响结论。）
- 比「登记时」与「old 重跑」：有几项不同（如 S6 搜索 2 → 1 个、K2 的改进门槛多没过几条）—— 来自今天的「现行」参数（W2 已开）与行情缓存的更新
  （2026-09-28 去掉 Yahoo 休市假行），不是股票池；判断股票池的影响只看 old 与 new。
- 过程里发现并改正的错误：第一次跑时 new 被误判成「不开 W2」（判断写成了模式名以 w 结尾，而 "new" 也以 w 结尾）→ new 侧全部作废、
  在干净的数据目录里重跑（修正 5e4ae46，测试已加）；old / oldw / neww / newus 不受影响。上面的数字都是修正后的。
